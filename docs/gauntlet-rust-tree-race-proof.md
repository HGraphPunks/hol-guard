# Inert tree-inventory race checks

Source change `4d549f835e3ba9318e71a20138b2e811c8d446a2` extends the inert `gauntlet-evidence` tree reader. It reopens the visible root after scanning and compares it with the held root descriptor before returning a digest. For symlink entries it reads the link target, performs the Linux `openat2` containment check relative to the held root, then reads the link again and refuses a changed target. These checks add refusal paths; the reader still reports no execution eligibility.

On 2026-10-20, the native ARM64 Docker context `colima` ran the pinned `rust:1.88.0-slim-bookworm` image (`sha256:38bc5a86d998772d4aec2348656ed21438d20fcdce2795b56ca434cf21430d89`) against the locked workspace using `cargo test --locked -p gauntlet-evidence --lib`. All 29 Linux evidence unit tests passed. Two new deterministic cases moved the visible SDK root after its scan or replaced a symlink target between its first read and containment check; both were refused with the expected error. The existing changed-file-after-first-chunk and inside-chain/escape cases also passed. The local container ran the code immediately before the 87-line Linux test module was moved unchanged into `tree_inventory_tests.rs`; macOS full-workspace tests, format and warnings-denied Clippy passed after that file move. On the merged PR head `65b63ed22f7a765335482dec2834d53949e3fd01`, the [ARM64 `arm64-binaries` job](https://github.com/hashgraph-online/hol-guard/actions/runs/39532618318/job/119001836865) and [Rust `contracts` job](https://github.com/hashgraph-online/hol-guard/actions/runs/39532618318/job/119001837069) both passed, exercising the final file layout.

This proof covers those scheduled mutation points only. It does not establish resistance to every directory/symlink interleaving, an adversary that can restore a prior state between observations, or Python/Rust reason-class parity across runner v1–v7. No retained VM deployment was inventoried or executed for this change. The Phase 1 asset-admission parent remains open.
