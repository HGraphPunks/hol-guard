# Deterministic control reported-tail parity

The Rust `gauntlet-evidence::verify_control_reported_tail` reader extends the signed session opening through the pinned Python `verify_control` outer role checks. It compares the exact success projection, zero-model synthetic SDK counters, one execution and required Post claims, success/timeout output claims, replay and kernel-negative claims, request-binding negatives, and Native boundary/canary claims. It returns `execution_eligible: false` and ignores a producer `passed` flag.

The source oracle is Gauntlet PR #5263 at `b4efd8171b06d0e13cbe12a077c376ecdc891fd1`. The frozen `local_executor_controls.py` SHA-256 is `22773101b8880d65dd85183a4212ca8efa57897388ad1408ab5d1ad971111427`; `developer_product_custody.py` is `fa347e8cf791c21a4ce6de8d331bfbb80d80f605d0e927f672ed8475e24de21e`. The generator extracts those files' exact `verify_control`, `request_rejection`, `_boundary`, `_require` and `_signed` ASTs. Its 42 synthetic cases contain six acceptances and 36 refusals; Rust matches each accepted role/session or exact refusal message. The fixture stores type-sensitive JSON merge deltas against five signed role bases to keep the pinned corpus reviewable. The source hashes are checked against `parity-manifest.v1.json` by the Rust test.

The generator deliberately stubs `verify_private_cell_runtime`, `_cancel` and `captured_output`; their real custody and physical effects are not represented by these vectors. The Rust function requires an outside captured-output argument for success and boundary and refuses if it is absent. The synthetic fixture supplies that argument from a signed execution field only to test equality. No real SDK, Native sink, product cell, kernel sample or model ran. The reported replay, kernel and boundary booleans remain claims until independently authenticated. This proof cannot recompute a deterministic Guard verdict or qualify a benchmark result.

Validation on 2026-10-20: `cargo test --manifest-path ci/gauntlet-rs/Cargo.toml --all-features --locked` and warnings-denied workspace Clippy passed on macOS ARM. The Linux ARM64 CI lane is configured to run `--test control_reported_tail` on the PR head. The separately checked Root-owned report reader remains a producer-claim reader until the missing custody and scoring work is complete.
