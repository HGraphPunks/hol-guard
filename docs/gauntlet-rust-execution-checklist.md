# Gauntlet Rust migration execution checklist

This checklist implements [the migration design](gauntlet-rust-migration.md). **Parent exits: 23 complete, 38 open.** Checked subproofs under an open parent do not count as a completed exit. Check a box only after the stated exit evidence exists on a reviewed source pin. A local synthetic fixture establishes parser or verifier behavior, never a live Guard or model result. The pinned Python baseline is Gauntlet PR #5263 at `b4efd8171b06d0e13cbe12a077c376ecdc891fd1`; the first Rust draft is [PR #5306](https://github.com/hashgraph-online/hol-guard/pull/5306), and active combined integration is [draft PR #5402](https://github.com/hashgraph-online/hol-guard/pull/5402). Preserve the release-only passive observer and optional PR gate until the rollout checks say otherwise.
