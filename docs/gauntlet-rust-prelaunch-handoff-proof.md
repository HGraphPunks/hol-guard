# Controller prelaunch pin/ack boundary

The shared Rust contract now defines a bounded canonical `hol-gauntlet-controller-prepared.v1` frame containing the worker's one-use job/source/deployment/generation identity, v2 started-marker digest, key-sidecar digest and public key. The matching `hol-gauntlet-controller-prelaunch-ack.v1` carries the job ID, SHA-256 of the exact prepared frame and SHA-256 of the canonical host pin record. The worker verifies all three against its own prepared values. Duplicate-key, noncanonical, oversized, changed-key and wrong-ack cases refuse.

The isolated host journal's `accept_prepared` operation first compares the frame's job, source, deployment and worker generation with the host's planned tuple. A mismatch writes no pin. It then writes and `fsync`s its one-use 0600 record, reopens it, compares its raw digest with the contract's expected host-record digest, and only then returns the ack. A second prepared frame for the same job cannot overwrite the record. The internal Rust worker launch now generates the sealed signing key, reserves the keyed started marker and writes the sidecar, then calls a required acknowledgement callback before it can open a job log or spawn the controller. After a valid ack, it checks cancellation, `CLOCK_BOOTTIME` expiry, its lease, key pin and controller/interpreter inputs again. A missing, stale or malformed ack leaves the job consumed without a child and blocks replay. The active deadline includes the acknowledgement wait.

This is still an unwired internal boundary. The callback is not connected to a bounded authenticated Lima transport or a live Rust host observer; no source-matched VM controller installation or fresh Rust-owned benchmark job has used it. The callback's future transport must enforce its own read/write deadline and deliver only the ack produced after host `fsync`. Neither the prepared frame nor the ack authenticates signed control records, process effects or a Guard verdict. All Rust observations remain ineligible and the PR gate remains passive.
